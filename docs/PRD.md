# 恐龙小丛林 · 产品需求
目标：从斜上方俯瞰的完整 3D 小箱庭。恐龙在温暖、宁静的迷你丛林里悠闲徘徊，面向手机和电脑，操作简单。

| 范围 | 验收要求 |
| --- | --- |
| 视觉 | 精致低多边形与黏土玩具质感；柔和阳光与自然阴影；简洁背景；整个岛屿居中完整 |
| 生态岛 | 树木高低错落，蕨类、藤蔓、苔藓、岩石、小溪和池塘丰富，但不会遮住恐龙主体 |
| 恐龙 | 可爱的三角龙、剑龙、长颈龙；比例协调，颈盾、角、背板和长脖子各有特点 |
| 行为 | 不同路线缓慢游走，停下吃草、喝水、抬头张望；避免树干、岩石、水体边界与彼此 |
| 动画 | 自然交替步态、脚掌着地、尾巴轻摆；不明显滑行、瞬移或穿模 |
| 环境 | 植物随风摇摆、水面涟漪、小昆虫、轻薄晨雾 |
| 交互 | 鼠标/触控旋转缩放；全景、池畔、俯瞰预设；点击恐龙显示名称与可爱动作；暂停恢复 |
| 手机 | 竖屏完整观看；按钮易点，介绍卡不盖住全部场景；横竖屏切换不丢失画面 |
| 素材 | 场景物体全部代码生成；不使用外部图片或 3D 模型；Three.js 等代码依赖正常安装 |
| 部署 | 纯静态构建，支持 GitHub Pages 子目录；main 推送后自动测试、构建并发布 |

性能目标：桌面接近 60 FPS，常见手机稳定可玩（争取 30 FPS 以上）；需要实测，不作为现有达标结论。优先降低像素比、阴影和几何负担，保留可辨识的恐龙与互动。

## 2026-10-03 第二轮 · 最新范围（覆盖上一轮扩展中的物种限制）
1. 深蓝儿童友好界面，场地可行走半径从8.15扩至11.5。主要按钮/居民文字约16px或以上，辅助文字至少13px，点击目标至少44px。

3. 选中后鼠标点/单指点地面指定目的地，绕开池塘、树干、岩石和居民；提供标记、行进、受阻及到达文字。拖动和多指操作不发移动指令。
4. 自动白天/傍晚/夜晚循环，允许手动选择；夜景有月亮、星光和萤火虫，模型与地面保持明亮可辨。
5. 自动旋转可开关，用户拖动时停止；背景音乐可开关，主动点击启动。
6. 拍照生成实际场景、品牌相框与本地时间，预览、PNG下载、按能力提供原生文件分享；保存到相册通过系统菜单或手机文件应用完成。
7. 中英双语保留，新功能完整翻译。移动端固定场景搭配可滚动面板，小屏可访问全部功能。
8. 用户提供美术参考后更新视觉方向：切面 low-poly 浮岛、角形树冠与浅色树干，恐龙全部具备真实低面数和面法线，场景/页头/面板/按钮/拍照弹窗同步青绿、橙金、靛蓝换肤。
9. 原创具有3D感的APP图标，提供高分辨率PNG与网站、主屏幕适配尺寸。以程序代码生成，不下载模型。

## Android 手机与平板扩展
- 输出可直接安装的通用 APK（Android 10+），离线内置同一场景与程序化 3D 图标，手机/平板横竖屏均可操作。
- 原生操作目标至少48px，竖屏平板采用上下布局；中文与英文共用网页翻译。
- 照片通过原生 MediaStore 保存到 Pictures/Dino Grove，保留品牌相框和本地拍摄时间；显示成功/失败并防止重复点击。
- 后台静音、回前台恢复、系统返回键逐层关闭。只加载内置内容，不添加网络或相册读取权限。
- 本轮交付调试证书签署的测试 APK，应用商店上架与长期发行签名不在本轮范围。验收明确区分真实 Android 模拟器、桌面触摸模拟及尚未执行的实体设备测试。
