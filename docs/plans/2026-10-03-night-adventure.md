# 星夜探险升级实施记录

用户本轮明确要求八项功能，取代上一轮「不新增霸王龙」的范围限制。继续使用现有 React / Three.js 静态架构，不引入外部图片、模型、音频或服务端。

## 范围和文件
- `src/navigation.mjs`：扩大活动范围，五居民出生点、碰撞体、可达路径、点击目的地及完成/受阻状态。
- `src/grove.ts`：扩大生态岛、霸王龙/迅猛龙程序造型与双足步态、地面拾取、目的地反馈、日夜照明、自动镜头旋转。
- `src/App.tsx`、`src/globals.css`、`src/i18n.ts`、`src/DinoPortrait.tsx`：深蓝儿童友好双语界面，五居民大标签、可滚动操作面板和固定场景、日夜说明、移动提示、音乐及照片预览。
- `src/music.ts`：本地 Web Audio 原创八音盒循环。默认关闭，主动点击启动，隐藏时静音，卸载时清理。
- `src/photo.ts`：保留实际场景内容，Canvas 绘制品牌相框和设备本地拍摄时间；返回 PNG、对象 URL 和文件名。
- `tests/navigation-check.mjs`、`tests/scene-check.mjs`、`tests/browser-check.mjs`：导航可靠性、场景数学和真实 WebGL/触控回归。

## 交互约定
1. 选择居民后，鼠标或手指轻点地面下达移动；拖动和双指缩放不下达指令。目的地会避开障碍，亮色标记伴随状态提示。
2. 初始白天，日夜自动循环；可手动选白天、黄昏、夜晚。夜间维持可辨识的模型、可读文字和操作亮度。
3. 自动旋转默认关闭；用户手动操作镜头后停止。动画减少偏好仍可显式开启旋转。
4. 拍照先生成带框预览，再选择下载或系统分享。网页不能直接写入手机相册；显示实际可用的保存路径，不虚称已入相册。
5. 五居民包含三角龙、剑龙、长颈龙、霸王龙和迅猛龙；保留招呼、投喂、漫游、喝水及三个镜头。
